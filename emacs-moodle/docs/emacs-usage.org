* 1. Instalação e Setup

O arquivo =init.el= na raiz deste repositório foi construído de forma reprodutível e autocontida.

** Como utilizar a configuração

Você pode iniciar o Emacs diretamente apontando para este arquivo de configuração:

#+BEGIN_SRC shell
# Iniciar o Emacs carregando este init.el específico:
emacs -q -l /home/wgn/mnt/ext4/Projects-Srcs/Projects-Srcs-Aulas-Moodle/emacs-moodle/init.el
#+END_SRC

Ou criar um link simbólico para a pasta de configuração padrão do Emacs:

#+BEGIN_SRC shell
mkdir -p ~/.config/emacs
ln -sf /home/wgn/mnt/ext4/Projects-Srcs/Projects-Srcs-Aulas-Moodle/emacs-moodle/init.el ~/.config/emacs/init.el
#+END_SRC


* 2. Treemacs (Navegação de Arquivos e Projetos)

O *Treemacs* é aberto automaticamente na inicialização do Emacs.

| Atalho      | Ação                                      |
|-------------+-------------------------------------------|
| ~<F8>~ / ~M-0~ | Focar / selecionar a janela do Treemacs |
| ~C-x t t~   | Alternar exibição do Treemacs (toggle)    |
| ~C-x t 1~   | Fechar outras janelas mantendo Treemacs   |
| ~C-x t d~   | Selecionar diretório no Treemacs          |
| ~C-x t B~   | Gerenciar favoritos/bookmarks no Treemacs |
| ~C-x t C-t~ | Localizar arquivo via Treemacs            |


* 3. Magit (Controle de Versão Git)

O *Magit* é a interface completa para operações do Git diretamente dentro do Emacs.

Para abrir o painel de status do Magit:
- Atalho: ~C-x g~ (=magit-status=)

** Comandos Rápidos no Painel Magit:

| Tecla | Ação                                          |
|-------+-----------------------------------------------|
| ~s~   | Stage (adicionar arquivo ou hunk ao commit)   |
| ~u~   | Unstage (remover arquivo ou hunk da staging)  |
| ~c c~ | Criar commit (~C-c C-c~ para confirmar texto) |
| ~P p~ | Push para o repositório remoto                |
| ~F p~ | Pull do repositório remoto                    |
| ~b b~ | Switch branch (alternar de branch)            |
| ~l l~ | Ver log de commits                            |
| ~q~   | Fechar a janela atual do Magit                |

** Atalhos Úteis no Dired:

* 5. YASnippet & Imagens Org-mode / LaTeX

** Inserção de Imagens no Org-mode

Criamos dois métodos para facilitar a inclusão de imagens com metadados de exportação (HTML, LaTeX/PDF e visualização no Emacs):

*** Método A: Via YASnippet (~img + TAB~)

Em qualquer arquivo ~.org~, digite =img= e pressione =TAB=. O snippet expandirá com navegação interativa pelos campos (use =TAB= para avançar para o próximo campo):

#+BEGIN_SRC org
#+CAPTION: Descrição da imagem
#+NAME: fig:rotulo
#+ATTR_HTML: :width 800px :align center
#+ATTR_LATEX: :width 0.8\textwidth :placement [htbp]
#+ATTR_ORG: :width 600
[[./images/nome_da_imagem.png]]
#+END_SRC

*** Método B: Via Org-Tempo (~<img + TAB~)

Digite =<img= e pressione =TAB= para expandir o template estruturado imediatamente.

*** Descrição dos Atributos Gerados:
- =#+CAPTION:=: Legenda exibida abaixo da imagem no documento exportado.
- =#+NAME:=: Identificador para referências cruzadas internas (ex: =[[fig:rotulo]]=).
- =#+ATTR_HTML:=: Define largura (=:width=) e alinhamento (=:align=) na exportação HTML.
- =#+ATTR_LATEX:=: Define dimensões (=:width 0.8\textwidth=) e posicionamento flutuante (=:placement [htbp]=) em PDF/LaTeX.
- =#+ATTR_ORG:=: Define o tamanho de visualização da imagem dentro do próprio buffer do Emacs.

*** Visualização de Imagens no Buffer Org:
- Atalho: ~C-c C-x C-v~ (alterna a exibição das imagens embutidas no buffer do Org-mode).

** Inserção de Vídeos no Org-mode (Exportação HTML e LaTeX)

Para incluir vídeos com player interativo no documento HTML exportado e link clicável na exportação LaTeX/PDF:

*** Método A: Via YASnippet (~video + TAB~ ou ~vid + TAB~)

Digite =video= ou =vid= e pressione =TAB=. O snippet expandirá os blocos de exportação com player HTML5 responsivo:

#+BEGIN_SRC org
#+CAPTION: Descrição do vídeo
#+NAME: vid:rotulo
#+BEGIN_EXPORT html
<div align="center">
  <video width="800" controls style="max-width: 100%; border-radius: 8px; box-shadow: 0 4px 8px rgba(0,0,0,0.15);">
    <source src="./videos-apresentacao/video.mp4" type="video/mp4">
    Seu navegador não suporta a reprodução deste vídeo.
  </video>
</div>
#+END_EXPORT
#+BEGIN_EXPORT latex
\begin{center}
\href{run:./videos-apresentacao/video.mp4}{\textbf{▶ Vídeo: Descrição do vídeo (Clique para abrir)}}
\end{center}
#+END_EXPORT
#+END_SRC

*** Método B: Via Org-Tempo (~<video + TAB~ ou ~<vid + TAB~)

Digite =<video= ou =<vid= e tecle =TAB= para expandir o bloco diretamente.

*** Como funciona a exportação para HTML e PDF:
- *HTML* (~C-c C-e h h~ / ~C-c C-e h o~): Insere o player de vídeo interativo HTML5 com controles completos (play, pause, volume, tela cheia).
- *PDF* (~C-c C-e l p~): Insere o link clicável direto para a mídia com comando nativo =run:=, permitindo que o leitor de PDF abra o vídeo diretamente no reprodutor de mídia do sistema operacional.

** Snippets LaTeX e Fórmulas

*** Equação LaTeX em Org-mode (~eq + TAB~)
Digite =eq= e tecle =TAB= dentro de um arquivo ~.org~:
#+BEGIN_SRC latex
\begin{equation}
\label{eq:rotulo}
  E = mc^2
\end{equation}
#+END_SRC

*** Ambiente de Figura em Arquivo LaTeX (~fig + TAB~)
Digite =fig= e tecle =TAB= dentro de um arquivo ~.tex~:
#+BEGIN_SRC latex
\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.8\textwidth]{imagem.png}
  \caption{Legenda da figura}
  \label{fig:rotulo}
\end{figure}
#+END_SRC

** Gerenciamento Geral de Snippets

| Atalho    | Ação                                             |
|-----------+--------------------------------------------------|
| ~C-c y i~ | Buscar e inserir qualquer snippet ativo          |
| ~C-c y n~ | Criar um novo snippet interativamente            |
| ~C-c y v~ | Visitar e editar arquivo de snippet existente    |

* 6. Busca e Navegação (Consult + Vertico)

A pilha moderna de completação facilita a navegação rápida em arquivos e buffers:

| Atalho      | Comando               | Ação                                                    |
|-------------+-----------------------+---------------------------------------------------------|
| ~C-s~       | ~consult-line~        | Busca interativa por linha no buffer atual              |
| ~C-x b~     | ~consult-buffer~      | Alternar buffers, arquivos recentes e bookmarks         |
| ~M-g g~     | ~consult-goto-line~   | Pular diretamente para o número da linha especificada   |
| ~M-g M-g~   | ~consult-goto-line~   | Pular para linha (combinação clássica)                  |
