1. Página 1: O que é o Ripple.js?

Ripple.js é uma biblioteca JavaScript leve e independente de framework, cujo objetivo é reproduzir o efeito visual de ondulação (ripple effect) ao clicar em um elemento — a mesma animação popularizada pelo Material Design, do Google, em botões, cards e outros componentes interativos.

Ao ser clicado, o elemento exibe um pequeno círculo que nasce no ponto exato do clique/toque e se expande suavemente até cobrir a área do componente, desaparecendo em seguida. Esse feedback visual reforça para o usuário que a interação foi reconhecida pela interface.

Objetivos de Aprendizagem:
  • Entender o propósito do efeito ripple em interfaces modernas.
  • Aplicar o Ripple.js a botões e outros elementos clicáveis.
  • Customizar cor, duração e comportamento do efeito.
  • Compreender, em linhas gerais, como o efeito é implementado por trás dos panos.

2. Página 2: Por que usar o Ripple.js?

O efeito de ondulação virou um padrão de usabilidade em várias plataformas (Android, Angular Material, MUI/React etc.), pois entrega feedback tátil visual imediato. Usar uma biblioteca dedicada, em vez de reimplementar o efeito manualmente em cada projeto, traz vantagens:

  • Simplicidade: basta marcar o elemento (via atributo ou classe) para que ele ganhe o efeito.
  • Consistência visual: mesma animação em todos os componentes da aplicação.
  • Baixo acoplamento: não exige um framework específico (funciona com HTML/CSS/JS puro).
  • Leveza: poucas linhas de JavaScript e CSS, sem dependências externas.
Atenção: existem diversas implementações e pacotes chamados "ripple" no ecossistema JavaScript (biblioteca standalone, plugins jQuery, componentes de frameworks como Angular Material e MUI). O princípio de funcionamento é o mesmo em todas; sempre confira a documentação oficial do pacote específico que seu projeto utiliza antes de aplicar em produção.

3. Página 3: Instalando e Configurando

A forma mais simples de utilizar o Ripple.js é incluir o script e a folha de estilos em uma página HTML. 

<!DOCTYPE html>
<html lang="pt-br">
<head>
  <meta charset="UTF-8">
  <title>Introdução ao Ripple.js</title>
  <link rel="stylesheet" href="ripple.css">
</head>
<body>
  <button class="btn" data-ripple>Clique aqui</button>

  <script src="ripple.js"></script>
</body>
</html>

Em projetos com bundler, a instalação costuma ser feita via npm: 

npm install ripple-effects

4. Página 4: Uso Básico

Basta marcar o elemento desejado — geralmente com um atributo (data-ripple) ou uma classe CSS — e inicializar a biblioteca. A partir daí, todo clique dentro do elemento dispara o efeito automaticamente. 

// Inicializa o efeito ripple em todos os elementos marcados na página
Ripple.init();

// Ou aplicando manualmente a um elemento específico
var botao = document.querySelector("#meu-botao");
Ripple.attach(botao);

.btn {
  position: relative;
  overflow: hidden; /* essencial para "recortar" o círculo dentro do elemento */
  padding: 12px 24px;
  border: none;
  border-radius: 4px;
  background-color: #2980b9;
  color: #fff;
  cursor: pointer;
}
Dica: a propriedade CSS overflow: hidden no elemento pai é fundamental — é ela que impede o círculo animado de "vazar" para fora dos limites do botão.

6. Página 6: Customização

A maioria das implementações de Ripple.js permite configurar cor, duração e opacidade do efeito, seja via atributos data-* no HTML, seja via opções passadas na inicialização. 

<button class="btn"
        data-ripple
        data-ripple-color="rgba(255,255,255,0.4)"
        data-ripple-duration="600">
  Salvar
</button>

Ripple.init({
  color: "rgba(255, 255, 255, 0.4)", // cor do círculo
  duration: 600,                     // duração da animação em ms
  easing: "ease-out"                 // curva de suavização
});

7. Página 7: Como o Efeito Funciona por Trás dos Panos

Mesmo variando de implementação para implementação, o princípio do efeito ripple costuma seguir os mesmos passos:

  1. Capturar o clique/toque, obtendo a posição relativa do evento dentro do elemento (offsetX, offsetY).
  2. Criar dinamicamente um elemento (normalmente um <span>) posicionado exatamente nesse ponto.
  3. Calcular o tamanho do círculo de forma que ele seja grande o suficiente para cobrir todo o elemento pai, mesmo a partir de um clique na borda.
  4. Animar a escala (de 0 a 1) e a opacidade (de um valor visível até 0), geralmente com CSS transition ou @keyframes.
  5. Remover o elemento do DOM ao final da animação, usando o evento transitionend ou animationend.
elemento.addEventListener("click", function (evento) {
  var circulo = document.createElement("span");
  var raio = Math.max(elemento.clientWidth, elemento.clientHeight);
  var rect = elemento.getBoundingClientRect();

  circulo.style.width = circulo.style.height = raio + "px";
  circulo.style.left = (evento.clientX - rect.left - raio / 2) + "px";
  circulo.style.top = (evento.clientY - rect.top - raio / 2) + "px";
  circulo.classList.add("ripple-circulo");

  elemento.appendChild(circulo);
  circulo.addEventListener("animationend", function () {
    circulo.remove();
  });
});
