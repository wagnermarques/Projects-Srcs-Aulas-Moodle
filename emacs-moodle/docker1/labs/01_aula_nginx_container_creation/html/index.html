🐳 Bem-vindo à Aula 1 de Docker!

Se você está visualizando esta página no endereço http://localhost:8080, seu container aula_nginx está rodando com sucesso!

🔍 O que está acontecendo aqui?

  • Port Mapping (8080:80): O Docker redireciona as requisições da porta 8080 do seu computador para a porta 80 padrão do servidor web Nginx dentro do container.
  • Bind Mount (./html:/usr/share/nginx/html): O diretório local html/ da sua máquina está montado diretamente no diretório de arquivos web do Nginx.

🧪 Teste Prático (Edição ao Vivo):

Abra o arquivo html/index.html no seu editor de texto, faça qualquer alteração no texto e recarregue esta página no navegador (F5).

Você verá que a alteração é instantânea, sem precisar reiniciar ou reconstruir o container!
