* Página 1: Atenção — "Ripple.js" Não é Uma Coisa Só

Ao pesquisar por "Ripple.js", é fácil confundir projetos completamente diferentes que compartilham o mesmo nome. Nesta aula vamos distinguir **três coisas** que aparecem sob o nome "ripple" no ecossistema JavaScript:

1. **O efeito visual de ondulação** ao clique — um *padrão de UI/UX* popularizado pelo Material Design, não uma biblioteca oficial única.
2. **=ripplejs/ripple=** — uma biblioteca reativa clássica de 2013 ("*a tiny foundation for building reactive views with plugins*"), hoje sem manutenção.
3. **=Ripple-TS/ripple=** — um framework de UI moderno e ativo, escrito em TypeScript, com arquivos =.tsrx= e reatividade granular.

* Página 2: O Efeito Visual "Ripple" (Padrão de UI)

O **efeito de ondulação ao clique** não é uma biblioteca específica — é um **padrão visual** popularizado pelo Material Design do Google: ao clicar em um elemento, um círculo nasce no ponto do toque e se expande suavemente até desaparecer, dando feedback de que a interação foi reconhecida.

Diversos pacotes implementam esse padrão sob nomes parecidos, mas o princípio é sempre o mesmo e pode ser feito com poucas linhas de JavaScript e CSS puros, sem depender de nenhuma biblioteca externa.

#+BEGIN_SRC css
.btn {
  position: relative;
  overflow: hidden; /* essencial para "recortar" o círculo dentro do elemento */
  padding: 12px 24px;
  border: none;
  border-radius: 4px;
  background-color: #2980b9;
  color: #fff;
  cursor: pointer;
}
#+END_SRC

* Página 4: Como o Efeito Funciona por Trás dos Panos

Mesmo variando de implementação para implementação, o princípio do efeito ripple costuma seguir os mesmos passos:

1. **Capturar o clique/toque**, obtendo a posição relativa do evento dentro do elemento.
2. **Criar dinamicamente um elemento** (normalmente um =<span>=) posicionado exatamente nesse ponto.
3. **Calcular o tamanho do círculo** de forma que ele seja grande o suficiente para cobrir todo o elemento pai, mesmo a partir de um clique na borda.
4. **Animar** a escala (de 0 a 1) e a opacidade (de um valor visível até 0), geralmente com CSS =transition= ou =@keyframes=.
5. **Remover o elemento** do DOM ao final da animação, usando o evento =animationend=.

#+BEGIN_SRC javascript
elemento.addEventListener("click", function (evento) {
  var circulo = document.createElement("span");
  var raio = Math.max(elemento.clientWidth, elemento.clientHeight);
  var rect = elemento.getBoundingClientRect();

  circulo.style.width = circulo.style.height = raio + "px";
  circulo.style.left = (evento.clientX - rect.left - raio / 2) + "px";
  circulo.style.top = (evento.clientY - rect.top - raio / 2) + "px";
  circulo.classList.add("ripple-circulo");

  elemento.appendChild(circulo);
  circulo.addEventListener("animationend", function () {
    circulo.remove();
  });
});
#+END_SRC

* Página 5: =ripplejs/ripple= — A Biblioteca Reativa Clássica (2013)

Este é o projeto disponível em [[https://ripplejs.github.io/][ripplejs.github.io]] e [[https://github.com/ripplejs/ripple][github.com/ripplejs/ripple]]. Ele se descreve como *"a tiny foundation for building reactive views with plugins"* — uma base minimalista para criar *views* reativas, com **interpolação de template** (=\{\{ \}\}=) e **data-binding** automático, complementada por um ecossistema de plugins opcionais (=each=, =computed=, =events=, =refs=, entre outros).

**Exemplo real de uso (conforme a documentação oficial):**

#+BEGIN_SRC javascript
var Person = ripple('<div>{{name}}</div>')
  .attr('name', { required: true, type: 'string' });

var person = new Person({ name: 'Tom' });
person.appendTo(document.body);

person.name = "Barry"; // O DOM é atualizado automaticamente
#+END_SRC

Note a diferença de filosofia em relação ao efeito visual da Página 2: aqui existe **estado** (a propriedade =name=) e o DOM reage a mudanças nesse estado — é uma biblioteca de *data-binding*, não um efeito de animação.

* Página 6: =Ripple-TS/ripple= — O Framework TypeScript Moderno

Este é um projeto **diferente e ativo**, disponível em [[https://github.com/Ripple-TS/ripple][github.com/Ripple-TS/ripple]]. É um framework de UI *TypeScript-first*, construído em torno de arquivos =.tsrx=, com reatividade granular, controle de fluxo nativo no template e estilos com escopo automático — comparável, em proposta, a Svelte ou SolidJS.

**Instalação:**

#+BEGIN_SRC bash
npx create-ripple
cd my-app
npm install
npm run dev
#+END_SRC

**Componente com estado reativo, usando =track()=:**

#+BEGIN_SRC typescript
export function Counter() @{
  let &[count] = track(0);
  const increment = () => count++;

  <button onClick={increment}>Count:{count}</button>
}
#+END_SRC

**Controle de fluxo nativo no template (=@if=/=@for=):**

#+BEGIN_SRC typescript
@if (condition) {
  <p>Show this</p>
} @else {
  <p>Show that</p>
}

@for (const item of items; key item.id) {
  <li>{item.name}</li>
} @empty {
  <li>No items</li>
}
#+END_SRC

**Estilos com escopo automático:**

#+BEGIN_SRC typescript
<>
  <p class="notice">Scoped text</p>
  <style>
    .notice {
      color: var(--notice-color);
      font-weight: 700;
    }
  </style>
</>
#+END_SRC
