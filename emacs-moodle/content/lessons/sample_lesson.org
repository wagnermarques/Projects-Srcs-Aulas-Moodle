* Page 2: Asymptotic Analysis

** Big-O Notation Definition
We say that \(f(n) = \mathcal{O}(g(n))\) if there exist positive constants \(c\) and \(n_0\) such that:

\[
0 \le f(n) \le c \cdot g(n) \quad \text{for all } n \ge n_0.
\]

** Code Example: Constant vs Linear Time
#+BEGIN_SRC python
def get_first_element(arr):
    # O(1) Constant Time
    return arr[0] if arr else None

def find_element(arr, target):
    # O(n) Linear Time
    for item in arr:
        if item == target:
            return True
    return False
#+END_SRC
