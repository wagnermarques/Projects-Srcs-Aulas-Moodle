:TYPE: multichoice
:SINGLE: true
:SHUFFLE: true

:END:
Qual a diferença fundamental entre declarar uma propriedade no construtor com `val` versus `var`?

- [X] `val` gera apenas o *getter* (somente leitura), enquanto `var` gera *getter* e *setter* (leitura e escrita). :: Correto! `val` torna a propriedade imutável externamente.
- [ ] `val` pode ter seu valor alterado a qualquer momento, mas `var` é constante. :: Incorreto. O comportamento é exatamente o inverso.
- [ ] `val` só funciona para números inteiros e `var` para textos (Strings). :: Incorreto. Ambos funcionam com qualquer tipo de dado.
- [ ] `var` elimina a necessidade de inicializar a variável. :: Incorreto. Variáveis em Kotlin devem ser inicializadas.
